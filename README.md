# Practical Data Science for Dynamic Humanities — Code Examples

Examples are organized by book, chapter, and reading order. Start with the first-instruction notebook: it contains only the first example from the book. Continue with the Understanding print() notebook for that section. The chapter-practice notebook collects the remaining Chapter 1 activities. Later notebooks are limited to their named section. The external-package example is a local Python source file with its own requirements and README. Download notebooks for a local Jupyter installation; Python files run with Python 3. The book website is https://learn.ds4dh.org/. Browser integration is prepared locally and awaits website deployment.
