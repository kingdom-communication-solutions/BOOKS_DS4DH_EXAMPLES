# Local package example

Create a virtual environment with Python 3.13 or 3.14, activate it, and run:

```console
python -m pip install -r requirements.txt
python visitor_total.py
```

Expected output: `Visitors: 12,000`.

On Windows create with `py -m venv .venv`; on macOS/Linux use `python3 -m venv .venv`.
Activation and interpreter selection are explained in the book. This package example is for local Python, not a browser installation command.
